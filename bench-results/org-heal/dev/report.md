## Ranked gaps

Ranked by the simulated excess cost of the unhealed cases (the price of not healing over the horizon).

1. **Repeated procedure that should be a skill** (small detected only, medium detected only, large detected only; +$31.49). Could heal it today: the hybrid strategy drafts a skill (created disabled; a person turns it on), or the skills suggestion flow. What stops the unattended path: synthesizer.ts fromFindings: skill_crystallization is a note on the deterministic strategy; service.ts planFor drops new skills without the skills.setEnabled port (the host wires none: bootstrap.ts), and grants to the new skill are never added by a plan.
2. **Ceremonial layer (coordinator with one report)** (small symptom healed, medium made worse, large detected only; +$15.86). Could heal it today: propose_org_change in a work run or the Architect retrospective (a person approves the new chart). What stops the unattended path: synthesizer.ts fromFindings turns ceremonial_layer into a note only; ratchet.ts chartProblems rejects any change to reportsTo, spawnable or the role set (chart_broken), so no evolve strategy can remove a layer.
3. **Role lacks a write tool it needs** (small detected only, medium symptom healed, large detected only; +$12.85). Could heal it today: a person, propose_org_change in a work run, or the Architect retrospective. What stops the unattended path: synthesizer.ts fromFindings adds only Read, Glob and Grep; ratchet.ts validateEvolutionPlan rejects the whole plan for any write or exec tool (write_tool_added / write_tool_to_readonly), also from the hybrid model.
4. **Missing specialty (root or lead does lookups itself)** (small missed, medium missed, large missed; +$10.62). Could heal it today: propose_org_change in a work run or the Architect retrospective. What stops the unattended path: telemetry.ts diagnose skips the root agent (isRoot) and has no finding for work a spawner does itself; ratchet.ts chartProblems rejects adding a role (chart_broken).
5. **Guard role (reviewer) on deep** (small missed, medium missed, large made worse; +$9.62). Could heal it today: deterministic evolve if the review work were short; otherwise a person. What stops the unattended path: telemetry.ts diagnose: the over-provisioned rule needs short work (avg turns <= 6, output <= 4,000); a review of 9 turns never qualifies, so cost waste on long-work roles is invisible. Note the gate does NOT protect a guard role's tier (only its prompt, tool removals and skills).
6. **Tier under-provisioned (builder on everyday)** (small detected only, medium made worse, large detected only; +$8.26). Could heal it today: interactive `orgai org evolve --apply` with a person approving the raise (two generations), the hybrid strategy with approval, propose_org_change in a work run, or the Architect retrospective. What stops the unattended path: service.ts applyCore: the post-run pass never sets allowSpendRaise, so spend.ts holdSpendRaises strips every raise (rule spend_held). Gate rules seen: role_cooldown, spend_held. Held raises: builder-a.staffing, builder.staffing, checker.tier.
